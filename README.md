# ART Prompt Architect

Turn a rough idea into a prompt another model can run. The brief goes in. Act as, Request, and Terms come out.

This writes the instruction. It does not do the task.

## v1.0.0

- Compose a detailed or concise prompt from a short idea
- Starters for an email, meeting notes, a plain explanation, and a plan
- Copy one section or the full prompt, or download it as Markdown
- Light and dark themes, remembered on this device
- Recent prompts stay on this device
